Historical manifests and failure reports remain immutable. Their old named paths resolve through transport-manifest.json. Identity aliases retain every original byte; base64 aliases decode to the original complete raw bytes, including NULs. Verify or recover with `python3 recover-evidence.py --root <checkout> --path <original-repo-relative-path> [--out <scratch-output>]`. The optional output belongs in a disposable scratch directory; decoded raw NUL logs must not be added to the tracked text corpus. Historical unclassified RED remains unclassified; newly observed classified product RED is separate. Harness deadline evidence is infrastructure and is not accepted product RED.
 Recovery accepts only recorded aliases and requires the historical byte count and hash. If checkout newline conversion changes an identity alias, it can recover the exact staged or committed Git blob; it never substitutes a current hash for the original. Base64 transport accepts checkout line endings while requiring the decoded original hash.
