## code_quality

### Helper correctness (checked empirically, pwsh 7.6.3, script EAP Stop + PNC true)

- **Scoping:** after `Invoke-BestEffort`, the script scope still reads `EAP=Stop` and `PNC=True`. A later raw `git` nonzero call still throws `NativeCommandExitException`. No preference leaks into `& $Sync`. On 5.1 the PNC assignment is an inert local.
- **Return value:** it returns a single Int32 (no stray pipeline output): 128 for a failing git, 1 for a missing executable, 0 on success. The caller's `$LASTEXITCODE` is 0 afterwards.
- **Scriptblock variables:** these (`$Src`, `$Ref`, `$Repo`, `$SrcDir`, `$CloneUrl`, `$Target`) resolve dynamically through the function scope. The helper's locals (`$Command`, `$code`) shadow none of them.
- **Output capture vs `*> $null`:** stdout is now collected into `$script:BestEffortOut` and discarded by the caller (`$null = ...`). Native commands have no other streams, and stdout was non-TTY before too. So nothing changes for git or gh behaviour, and stderr is still discarded.
- **Terminating-error reliance:** no call site relied on termination for control flow. The only behaviour changes are the intended ones:
  - 5.1 stderr no longer exits 1.
  - Missing git: the guard passes, the local `-Repo` path syncs, and the clone path exits 3. That is sh parity (`|| true`, rc 127).
- **Sync failure is still terminal:** aai-sync.ps1 has no top-level `exit N`. It fails by throwing under the script-scope Stop, which still propagates. The masking of the post-sync `$LASTEXITCODE` by `git status` is not new.
- **5.1 syntax:** the typed catch, `[System.Uri]::new` (PS5+) and the scriptblock params are all 5.1-safe. CI 5.1 legs are green (r2).

### NON-BLOCKING

  - Every helper call ends with `$global:LASTEXITCODE = 0`, and the guard call runs first.
  - So the wrapper's `-StaleCode 0` never reaches a clone attempt. Every clone attempt starts from a stale 0 whatever the caller set.
  - The test's title ("a stale caller exit code ... does not leak") and the spec row description overstate what it isolates.
  - What actually guards the edge case is the helper's own trailing reset feeding the next call. 3588 already catches it.
  - Fix: retitle and redescribe the test, or drop `-StaleCode`. The spec row also needs a measurement amendment, so this is better batched with the open `fu-amend-spec-update-ps1-git-stderr` sign-off than done now.
- **NB2 (fix-now, optional): the CHANGELOG has one inaccuracy and one gap.**
