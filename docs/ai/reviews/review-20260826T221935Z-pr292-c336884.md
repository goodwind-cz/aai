### NB-1 — failed `--write` can partially mutate mirrors

At `.aai/scripts/sync-harness-skills.mjs:373-410`, each source skill is parsed
inside the same loop that immediately writes its target. A scratch fixture
proved the bite: source `a` was valid and changed, source `b` lacked its closing
frontmatter fence, and target `a` began stale. `--write` exited 2 at `b`, but
`.agents/skills/a/SKILL.md` had already changed from `description: old a` to
`description: new a`; `b` was absent. A failed structural-validation command
therefore leaves a partial generated state.

Recommended disposition: **remediate-in-tree**. Pre-read and parse all source
skills (and preferably build all expected outputs) before the first filesystem
mutation, then add a regression that snapshots every mirror, plants a malformed
