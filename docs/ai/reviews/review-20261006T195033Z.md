a `worktree_create` lifecycle record and the later final metrics summary. The
factory report previously selected every object carrying `ref_id`, so it
rendered both a zero-valued pseudo-ride and the real 14-run ride.

the same `isMetricsFlushRecord` contract already owned by metrics flush,
dispatch, and docs audit. That removes the divergent consumer rule rather
than special-casing `worktree_create`. `TEST-043` first reproduced the defect
with two rows and then passed with exactly one populated row. The existing
real-ledger shadow model now independently excludes lifecycle records instead
of importing the production predicate, preserving its value as a non-
tautological oracle.
