### NB-1 — invalid manifest diagnostics can be hidden by source parsing

At `.aai/scripts/sync-harness-skills.mjs:326-347`, the generator parses every
source model before `validateManifest()`. This preserves write atomicity, but it
gives source syntax errors precedence over manifest topology errors. With both
an undeclared existing mirror and malformed source, an operator sees only the
source fence error, repairs it, reruns, and only then learns the declared
transform is incomplete. More importantly, it violates AC-03's required tree
diagnostic for that input.

Recommended disposition: **remediate-in-tree**. Validate the manifest against
the enumerated source names before parsing source bodies; both checks still run
before any write. Add one combined-invalid fixture asserting exit 2 names the
undeclared tree even when a source file is malformed.
